# 鸿蒙小说爬虫应用

这是一个基于鸿蒙系统的52书库小说爬虫应用，将原有的Python爬虫功能移植到了鸿蒙平台。

## 功能特性

- 📚 从52书库网站爬取小说内容
- 💾 自动保存为本地文本文件
- 📱 友好的移动端用户界面
- 📖 查看和管理已下载的小说
- ⚡ 支持批量爬取多页内容

## 技术架构

### 核心组件

1. **HttpClient.ets** - HTTP客户端工具类
   - 替代Python的requests库
   - 支持重试机制和超时设置
   - 自动处理请求头和编码

2. **HtmlParser.ets** - HTML内容解析器
   - 替代Python的BeautifulSoup
   - 提取小说正文内容
   - 清理广告和无关元素

3. **FileManager.ets** - 文件管理系统
   - 处理小说文件的保存和读取
   - 管理下载目录
   - 支持文件列表查询

4. **NovelCrawler.ets** - 爬虫核心控制器
   - 整合所有功能模块
   - 控制爬取流程
   - 提供进度反馈

### 用户界面

**Index.ets** - 主界面包含：
- URL配置输入区域
- 页码范围设置
- 文件名自定义
- 实时进度显示
- 已下载小说列表
- 查看和删除功能

## 使用方法

### 1. 配置爬虫参数

在应用界面中输入：
- **基础URL**: 小说页面的URL（会自动转换为模板格式）
- **起始页码**: 爬取的起始页面编号
- **结束页码**: 爬取的结束页面编号
- **输出文件名**: 保存的文件名称

### 2. 示例URL格式

```
输入: https://www.52bqg.com/book_123/456.html
自动转换为: https://www.52bqg.com/book_123/{}.html
```

### 3. 开始爬取

点击"开始爬取"按钮，应用会：
1. 验证输入参数
2. 逐页请求小说内容
3. 解析提取正文
4. 保存到本地文件
5. 显示实时进度

### 4. 管理下载内容

- **查看**: 点击小说列表中的"查看"按钮
- **删除**: 点击"删除"按钮移除不需要的小说
- **刷新**: 点击"刷新列表"更新小说列表

## 开发说明

### 项目结构

```
entry/src/main/ets/
├── pages/
│   └── Index.ets          # 主界面
├── utils/
│   ├── HttpClient.ets     # HTTP客户端
│   ├── HtmlParser.ets     # HTML解析器
│   ├── FileManager.ets    # 文件管理器
│   └── NovelCrawler.ets   # 爬虫核心
└── entryability/
    └── EntryAbility.ets   # 应用入口
```

### 权限配置

已在`module.json5`中配置必要权限：
```json
{
  "requestPermissions": [
    {
      "name": "ohos.permission.INTERNET"
    }
  ]
}
```

### 注意事项

1. **网络权限**: 应用需要网络访问权限才能正常工作
2. **URL格式**: 确保输入正确的52书库小说页面URL
3. **页码范围**: 起始页码不能大于结束页码
4. **文件命名**: 支持自定义文件名，会自动添加.txt扩展名
